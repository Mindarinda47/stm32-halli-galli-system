# Contribution

## 작성 원칙

- 직접 작성한 범위만 `구현`이라고 표현합니다.
- 팀원 코드를 수정·연결한 경우 `통합 지원` 또는 `연동 수정`으로 구분합니다.
- 기억과 보존 코드가 충돌하면 보존 자료를 우선하고 `확인 필요`로 표시합니다.
- 전체 통합 소스를 보유하지 않으므로 코드 줄 수나 기여율을 임의로 계산하지 않습니다.

## 공식 역할

최종 보고서의 역할 분담에는 다음 다섯 항목이 개인 역할로 기록되어 있습니다.

- 코드 최적화
- 인터페이스 설계
- 디버깅
- 테스팅
- 하드웨어 설계

당시 경험 회고와 보고서의 역할 기록이 서로 일치하므로 포트폴리오의 개인 기여 근거로
사용합니다.

## 직접 구현한 기능

### 할리갈리 LCD 인터페이스

- 카드와 점수를 LCD 화면에 시각화하는 인터페이스를 구성했습니다.
- 무작위 플레이어 카드와 컴퓨터 카드, 점수와 최종 결과의 화면 흐름을 설계했습니다.
- 최종 통합 후 카드 진행과 점수 변화가 화면에 반영되는지 반복 확인했습니다.

### 스마트폰 터미널 결과 출력

- 게임 결과를 스마트폰 터미널에서 확인할 수 있는 출력 흐름을 구성·점검했습니다.
- 진행 중 보상·감점과 승패 결과가 스마트폰 터미널로 전달되는지 통합 테스트했습니다.

### 하드웨어 구성과 통합 안정화

- breadboard 위에 사용할 부품의 배치와 연결 구조를 설계했습니다.
- 점수 계산, 버튼 입력, 게임 진행 오류를 재현하고 조건과 상태 값을 바꿔가며
  디버깅했습니다.
- 공식 담당으로 한정되지 않았던 전체 코드 최적화와 반복 테스트도 자발적으로
  수행했습니다.
- 포트와 안정성 제약에 따른 1인 대 컴퓨터 구조, PIR 센서 위치 변경 등 최종 설계
  변경이 게임 흐름에 반영되는지 확인했습니다.

## 보존된 코드와의 관계

### 터치 센서 코드

- 현재 확인: GPIO 입력에 따라 출력 핀을 제어하는 독립 실험
- 포트폴리오 관계: 사용자가 대표 부분 코드로 확인
- 최종 프로젝트 반영 범위: 전체 통합 소스가 없어 세부 대조 불가
- 공개 표현: 터치 입력 처리 경험을 보여주는 보존 코드로 한정

### 초음파 센서 코드

- 현재 확인: GPIO Trigger와 TIM2 counter로 Echo 시간을 측정하는 독립 실험
- 포트폴리오 관계: 사용자가 대표 부분 코드로 확인
- 최종 프로젝트 반영 범위: 전체 통합 소스가 없어 세부 대조 불가
- 공개 표현: 센서 timing 처리 경험을 보여주는 보존 코드로 한정

## 통합 과정에서 수행한 일

- 개별 기능의 상태와 변경 사항을 팀 채팅방에서 공유하고, 발표 전날 실습실에서
  하드웨어와 코드를 함께 통합했습니다.
- 단독 테스트를 통해 전체 게임 구조를 미리 파악하고, 통합 단계에서는 점수·버튼·게임
  진행 문제를 중심으로 반복 검증했습니다.
- 팀원이 막힌 문제는 함께 코드를 살펴보고 해결 방향을 논의했습니다.

## 공개용 기여 요약

> STM32 기반 할리갈리 팀 프로젝트에서 LCD 카드·점수 인터페이스와 스마트폰 터미널
> 결과 출력 흐름을 구성했습니다. breadboard 하드웨어 배치와 전체 코드 구조를 파악한
> 뒤, 점수 계산·버튼 입력·게임 진행 오류의 디버깅과 반복 테스트를 자발적으로
> 수행해 최종 시연과 과제 통과에 기여했습니다.
