# Copyright and Publication Scope

## 공개 가능한 자료

- 본인이 직접 작성했다고 확인한 application code
- 본인이 직접 작성한 README와 기술 설명
- 2026년에 독립적으로 작성한 test code
- 개인정보를 제거하고 촬영·공개 권한을 확인한 이미지
- 팀원 동의를 받은 공동 결과 이미지

## 공개하지 않는 자료

- 교수 제공 PDF·DOCX·PPT·과제 명세·예제
- 개인정보가 포함된 보고서 원문
- 작성자를 확인할 수 없는 팀원 코드
- 팀원의 동의를 받지 않은 사진·영상
- 출처와 license가 명확하지 않은 LCD·touch driver
- IDE build 산출물과 binary

## STM32 및 vendor code

STM32 standard peripheral library, CMSIS, startup code는 각 배포본의 license를 따라야
합니다. 이 저장소에는 vendor source를 무단 복제하지 않고, 필요하면 공식 package를
외부 dependency로 명시합니다.

## 보존 코드

터치·초음파 코드를 대표 부분 source로 포함합니다. 개인정보·공개
검토를 위해 원본 주석은 제거했으며 제어 흐름은 수정하지 않았습니다. 수업 제공 skeleton이
확인되면 직접 작성 부분을 구분하고 필요한 최소 범위만 유지합니다.

## 팀 프로젝트 표현

- 프로젝트 전체 결과는 `팀이 완성`했다고 표현합니다.
- 본인 기여는 확인된 기능 단위로 표현합니다.
- 팀원 이름과 개인정보는 공개하지 않습니다.
- 전체 통합 소스가 없다는 사실을 숨기지 않습니다.
